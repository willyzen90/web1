# ⚡ CHRONO//NEXUS - Reloj Digital Cyberpunk

Este repositorio contiene una aplicación web completa de un **Reloj Digital Cyberpunk** desarrollada en un solo archivo `index.html` con HTML5, CSS3 y JavaScript puro.

## 🚀 Contenido del repositorio
- `index.html`: Aplicación web con reloj en tiempo real (12h/24h), temas (Cyberpunk, Oscuro, Claro), cronómetro con vueltas y alarma sonora.
- `README.md`: Documentación del proyecto.

## 📌 Cómo publicar en GitHub Pages
1. Descarga y descomprime este archivo `.zip`.
2. En GitHub, crea un repositorio público (ej. `reloj-digital`).
3. Sube los archivos `index.html` y `README.md`.
4. Ve a **Settings > Pages**, elige la rama `main` y guarda. ¡Tu sitio estará online!
